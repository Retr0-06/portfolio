# LeadKit: інструменти для сайтів клієнтів

Кожен інструмент — одна HTML-сторінка. Усе, що змінюється під клієнта, лежить в об'єкті `CONFIG` на початку скрипта: назва, ціни, послуги, питання, години роботи.

## Налаштування під нового клієнта (1–2 години)

1. Скопіюй папку інструмента (`calculator`, `quiz` або `booking`) у `clients/<назва-клієнта>/`.
2. Заміни `CONFIG`: послуги, ціни, валюту, тексти.
3. Заміни кольори й шрифти в `:root` під бренд клієнта (візьми з його сайту).
4. Прибери верхню смугу `.demo`.
5. Підключи бекенд за інструкцією в `apps-script.gs` (Google Таблиця + Telegram-бот клієнта).
6. Перед `lead.js` додай рядок з адресою бекенду:
   ```html
   <script>window.LEADKIT_ENDPOINT = "https://script.google.com/macros/s/…/exec";</script>
   ```
7. Надішли тестову заявку разом із клієнтом.

## Як вставити на сайт клієнта

Інструмент живе на GitHub Pages, а на сайт клієнта вставляється один блок коду:

```html
<iframe src="https://retr0-06.github.io/portfolio/clients/<назва>/"
        style="width:100%;height:1100px;border:0" loading="lazy"
        title="Калькулятор вартості"></iframe>
```

- **Tilda:** блок T123 (HTML-код).
- **WordPress:** блок «Користувацький HTML».
- **Wix:** Додати → Вставити код → Вбудувати HTML.
- **Horoshop / Prom:** сторінка з HTML-редактором або блок «HTML-код».

Висоту (`height`) підбери так, щоб на телефоні не було внутрішньої прокрутки.

## Без бекенду

Якщо `LEADKIT_ENDPOINT` не задано, сторінка працює в демо-режимі й показує, як виглядатиме повідомлення в Telegram. Нічого не надсилається.
